# 座標與地圖規則

## 兩套座標
- **世界座標**：整張地圖。原點在正中央，+x 東、+z 南，邊長 `WORLD.size`（現在 2048 公尺）。玩家、船、伺服器的位置都是世界座標。
- **港座標**：母港自己的設計圖座標。母島在 `WORLD.home.islandLocal`（現在 (0, 40)），+z 是港口面海那一側。岸壁、浮橋、商店、停船格、碰撞矩形、港口的著色器矩形全部用港座標寫（`src/layout.js`、`src/harbor.js`、`src/terrain.js` 的 `HOME`）。
- 兩邊互轉只用 `src/frame.js`：`toWorld` / `toLocal`，方向（船頭、人面向）用 `headingToWorld` / `headingToLocal`。

## 參數集中在 `src/config.js`，不要寫死
| 參數 | 意義 |
|---|---|
| `WORLD.size` | 地圖邊長 |
| `WORLD.home.center` | 母島中心在世界的位置 |
| `WORLD.home.harborFacingDeg` | 港口面向（正北 0、順時針；135 = 東南） |
| `WORLD.home.islandLocal` | 母島中心在港座標的位置（設計圖參照點，通常不動） |
| `WORLD.waveFromHarborBackDeg` | 浪向相對港口背面的偏斜（浪由港口背面吹來，港內才是背風面） |

想搬島、轉港口，只改 `config.js`，不用動其他檔案。

## 寫程式的規則
1. **不准在別處寫死世界座標、地圖大小、港口位置或朝向。** 要用就從 `config.js` / `frame.js` / `layout.js` 取。
2. 港口的東西（矩形、停船格）一律寫港座標，要給世界用的在 `layout.js` 底下有 `*_W` 世界版（`SELL_W`、`SHELF_W`、`SPAWN_W`、`QUAY_CENTER_W` ……）；`onDeck`、`pontoonY`、`inHarbor`、`berthPose` 吃/回世界座標，內部自己轉。
3. 蓋港口模型用港座標，整個 group 用 `placeInHome()` 擺進世界；著色器裡的港口矩形用 `homeGlsl` 的 `homeLocal()` 轉回港座標再比（`uHome`）。
4. `makeHarbor` 之後呼叫 `worldizeHarborLists()`，把樁、消波塊、繫纜樁、路燈清單轉成世界座標。
5. 碰撞矩形是軸對齊的（港座標），所以世界座標的位置要先 `toLocal` 再比；不要把矩形直接當世界座標用。
6. 島的清單：`terrain.js` 的 `ISLANDS` 是世界座標（佈景、著色器、伺服器用），地形本身用港座標算（`LOCAL_ISLANDS`）。著色器的島陣列長度用 `ISLANDS.length`，不寫死。
7. 太陽的水平方向與浪向都跟著港口轉（`main.js` 的 `homeSun`、`WAVE_ANGLE`），港口與日照、避浪的關係不變。

## 現況
- 只有一座母港島；其他五座島（西嶼、雙峰島、北礁、沙洲島、東嶼）已移除，它們的魚種特產（`SPECIALTY`）暫時釣不到。
- 母島在地圖左上角一帶，港口面向東南（右下）。
