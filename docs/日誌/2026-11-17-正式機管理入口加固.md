## 正式機

- `valheim-allow-iap-ssh` 優先序 900 允許 IAP 的 IPv4 範圍連 TCP 22；`valheim-deny-direct-admin` 優先序 910 拒絕直連 TCP 22、3389。兩條規則皆以共用 VM 的網路標籤套用。Stormcast 的部署、公告及統計腳本改走 IAP，這台電腦的 Valheim 管理與設定同步腳本也更新為 IAP。
- 先比對 IAP 與直連的 SSH 主機金鑰，再測登入與傳檔。關閉直連後重新以 IAP 登入，確認 TCP 22、3389 無法從公開 IP 連接，HTTPS 與 Valheim 的遊戲埠仍可用。Valheim 的服務 PID 未變。
- Caddy 已套用明確 `/admin` 封鎖、官方 WebSocket 路由、5 秒讀取標頭上限、16 KB 標頭上限與 `connect-src`。Chrome 已實測第三方 WebSocket 被阻擋，官方 WebSocket 仍收到大廳資料。
- 遊戲程式改由 root 擁有，服務只需讀取程式；存檔目錄與檔案分別設為 700、600，服務使用 `UMask=0077`、唯讀系統檔案與獨立暫存區。驗證服務帳號可寫資料目錄、無法寫程式，其他帳號無法讀存檔。正式服只接受官方 Origin。設定異動前已保存原始 Caddy 與 systemd 設定於正式機 root 私有目錄。

## 遊戲程式

- 加上全服握手速率與新訪客速率上限，分散來源也計入。全服握手瞬間允許 256 次，每分鐘補 480 次；新訪客瞬間允許 48 次，每分鐘補 60 次。已存在的存檔代碼不占用訪客額度。
- 66 項回歸測試通過。另以本機記憶體串流走實際 HTTP 與 WebSocket，確認訪客限額、進房、重連、`hello` 超時。
- 正式機的遊戲程式仍為複核到的舊部署版本。本次只套用主機與代理設定，遊戲程式的每來源與全服新限額留在本機提交。大規模流量若在主機之前壓滿網路，需由上游處理。
