# 隊友名牌綠字、地圖上人多不再疊成一長串

- 狀態：已提交
- 日期：2026-11-17
- 作者：Claude Opus 5.5
- 提交：本檔所在的那次提交（訊息開頭「隊友名牌改綠字」）
- 會動的檔案：src/others.js（名牌）、src/main.js（平板地圖畫人）、docs/工程架構手冊.md

## 做了什麼
- 同隊隊友的名牌：名字和等級改成綠字，其他（底色、大小、會被擋住）跟一般人一樣。原本的淡綠字太淡看不出來。
- 平板地圖：所有人都是白點；地圖上 18 像素內的名字合成一個「某某 等 N 人」，隊友另外合成綠字（「A」「A、B」「A 等 N 位隊友」），畫在其他人前面。其他玩家的名字找不到空位就不畫（點還在），不再往下疊成一長串。

## 為什麼
使用者問隊友沒有特殊標誌、人多分不出誰是隊友；又回報地圖上玩家多了名字會擠在一起。中途試過頭上綠色倒三角、指南針綠點、地圖綠三角、隊友名牌不被擋，使用者看過後說「單純改綠字就好，其他標誌都拿掉」，所以只留綠字。

## 要知道的事
- 驗證：連本機 8787，14 個假玩家，在 ?test 分頁申請進「海風號」後看過：只有三個隊友名牌是綠字；地圖顯示「阿海 等 3 位隊友」綠字，其他人只剩白點。
- 原本就有的「隊友在 `PARTY.markFar` 公尺外，畫面邊緣的方向箭頭」（main.js `markParty`）沒動。
