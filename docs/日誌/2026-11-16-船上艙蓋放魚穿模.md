# 修正船上艙蓋放魚與放魚箱穿模問題

- 狀態：已提交（還沒上線）
- 日期：2026-11-16
- 作者：Gemini 4 Hydrogen (XHigh)
- 提交：見 git log
- 會動的檔案：src/boat.js、src/fish.js、src/fishBox.js、src/main.js、tools/collision.test.js

## 做了什麼
- `src/boat.js`：在 `Boat` 新增 `onHatch(lx, lz)` 與 `deckLocalY(lx, lz)`（於漁船／大漁船 `0.28` 公尺高的艙蓋範圍內抬高 `0.28`），並讓 `walkDeckY(x, z)` 共用 `onHatch`。
- `src/fish.js`：修正 `drop`、`worldPos`、`_floor` 改用 `walkDeckY`（透過 `_boatDeckY` 相容測試 mock），`_pose` 改用 `deckLocalY` 讓魚正確停在艙蓋頂面；另以 `_boatCanMove` 防止低甲板的魚直接滑上或低跳穿過 `0.28` 公尺高的艙蓋側面。
- `src/fishBox.js`與`src/main.js`：甲板魚箱擺放位置 `_place` 改用 `deckLocalY`，`putBoxDown` 高度差檢查改用 `walkDeckY`。
- `tools/collision.test.js`：新增測試驗證漁船與大漁船艙蓋頂面放魚、高拋著陸、低拋反彈、傾斜滑動邊界與魚箱放置高度。

## 為什麼
漁船（`fisher`）與大漁船（`trawler`）前甲板的棕色艙蓋高出甲板 `0.28` 公尺，原本只有玩家行走的 `walkDeckY` 有加上艙蓋高度；魚與魚箱仍以 `spec.deck`／`deckY` 擺放與碰撞，導致放在艙蓋上的魚沉入棕色木箱內穿模。

## 要知道的事
- 驗證：`node --test tools/collision.test.js tools/gameplay.test.js tools/security.test.js`（37 項全數通過）、`npm run build` 通過；並於 `http://localhost:5173/?test` 實測在漁船艙蓋放下與拋出鮪魚，確認魚完整停在艙蓋頂面、準星可正常顯示「按 E 拿起鮪魚」、主控台無錯誤。
