# 海浪往前推的速度放慢到 0.6 倍

- 狀態：已提交（還沒上線）
- 日期：2026-11-15
- 作者：Claude Sonnet 5.5
- 提交：ffc987f
- 會動的檔案：src/weather.js、src/ocean.js、src/oceanWorker.js

## 做了什麼
新增 `WAVE_SPEED = 0.6`（在 `weather.js`，放在 `WAVE_LOOP` 旁邊），乘在每個波的角頻率 ω 上。顯示用的 GPU 著色器（`ocean.js`）和背景浮力用的 worker（`oceanWorker.js`，由初始化訊息帶 `speed`）都用它。

## 為什麼
使用者覺得海面流動快得不合理，澄清後是「波往前推的速度太快」（不是浪高）。深水波的物理速度對這個尺度的畫面偏快。

## 要知道的事
- 角頻率仍然四捨五入成 2π/2048 的倍數，多人才對得上時間，所以實測速度比約 0.67，不是剛好 0.6。
- 湧浪（swell）不受影響。
- 動到波速的任何程式，兩邊（著色器與 worker）要一起改，否則船的浮力和看到的海面會對不上。
- 實際在遊戲裡的手感只由使用者看過一次，結論是「先這樣」。
