# 頭上名牌：等級放在名字前面

- 狀態：已提交
- 日期：2026-11-17
- 作者：Claude Sonnet 5.5
- 提交：見 git log（標題「名牌改成等級在前、名字在後」）
- 會動的檔案：src/others.js

## 做了什麼
別人頭上名牌的順序改成「稱號膠囊 → Lv.N → 名字」（原本是名字在前、Lv 在後）。名牌寬度算法沒變（等級那一段的寬度加間距，只是畫的順序換了）。

## 為什麼
使用者看截圖：名字叫「1」的玩家顯示「1 Lv.1」，看起來像等級和名字混在一起，要求 Lv.1 在前、名字接在後面。

## 要知道的事
只改頭上名牌（`nameTag`）。申請加入船隊的提示（`名字（Lv.N）`）、聊天室等其他地方沒動。只做了語法檢查，沒開畫面看（瀏覽器窗格當下是隱藏的）。
