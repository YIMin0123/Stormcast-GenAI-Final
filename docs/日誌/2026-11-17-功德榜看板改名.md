# 港口看板「漁會功德榜」標題改成「漁會捐贈榜」

- 狀態：已提交
- 日期：2026-11-17
- 作者：Claude Sonnet 5.5
- 提交：見 git log（標題「看板標題改成漁會捐贈榜」）
- 會動的檔案：src/boards.js

## 做了什麼
母港商店、大港榮譽榜亭的 3D 看板標題（`TITLES.donate`）從「漁會功德榜」改為「漁會捐贈榜」，副標不變。

## 為什麼
使用者看截圖要求寫成「漁會捐贈榜」。

## 要知道的事
只改了看板。平板榜單 app 的分頁（「📜 漁會功德榜・稱號」）、伺服器每週重置訊息、手冊與程式註解的「功德榜」都還是舊名，沒有一起改（使用者只指了看板）。
