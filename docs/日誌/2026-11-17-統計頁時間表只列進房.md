# 管理統計頁「當天時間表」只列誰進了遊戲

- 狀態：已提交
- 日期：2026-11-17
- 作者：Claude Sonnet 5.5
- 提交：見 git log（標題「統計頁時間表只列進房」）
- 會動的檔案：server/statsPage.js

## 做了什麼
`/admin/stats` 的「當天時間表」只列 `join`（進房）事件；離開、斷線、斷線接回、換名、伺服器啟動都不列。

## 為什麼
使用者看截圖覺得太雜，只要看誰進了遊戲。

## 要知道的事
- 只改頁面顯示，伺服器照舊記全部事件（玩家表的場次、時長、釣到幾條、賺花多少都靠它們）；要恢復只要改回 `filter`。
- 「說明」欄現在只剩「新玩家（第一次出現）」；每場玩多久、釣幾條在時間表看不到了（玩家表還有總計）。
- 驗證：用空報告產生頁面、內嵌腳本語法通過；沒有開畫面看實際表格（8787 的伺服器不是我啟動的，沒去重開它）。要看新版需重開 8787 的伺服器。
