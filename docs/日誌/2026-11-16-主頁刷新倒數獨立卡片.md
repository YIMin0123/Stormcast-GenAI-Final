# 主頁全服刷新倒數獨立成卡片

- 狀態：已提交（還沒上線）
- 日期：2026-11-16
- 作者：Gemini 4 Hydrogen (High)
- 提交：見 git log（標題「主頁全服刷新倒數獨立成卡片」）
- 會動的檔案：index.html、src/announce.js

## 做了什麼
- 把 `#refreshBox` 從 `#notice` 裡拉出來，改成獨立的 `.card` 放在 `#menu` 內：
  - 桌機寬螢幕（> 1100px）：固定在右上角（`top: 58px; right: 28px`），避開後方的 `#hud` 與中間的登入／選房卡片，倒數文字不折行（`white-space: nowrap`）。
  - 窄視窗（<= 1100px）：排在 `#menuName` 與 `#notice` 之間並順便將 `#menu` 改為 `align-content: safe center`（`flex-start` 回退），修掉原本窄視窗總高度超過視窗時 `#menuName` 頂部往負方向捲動被裁切的問題。
  - 手機橫放（`body.touch`）：因 `#notice` 隱藏，將 `#refreshBox` 縮小並擺在登入卡片旁一起置中顯示。
- `src/announce.js` 的 `NOTICE.items[1]` 拿掉「，倒數見下方」，讓主頁公告與平板公告 app 的文字都準確。

## 為什麼
加入「更新資訊」後 `#notice` 變長且出現捲軸，原本嵌在最底部的全服刷新倒數要往下捲才看得到，且寬度不足導致「秒」字折行。

## 要知道的事
- 驗證：`npm run build` 通過；在 `?test` 實測 `1280x720`、`800x600` 版面與捲動正常（改為 `safe center` 前亦已於 `?test&touch` `844x390` 確認並排無重疊）。
- 這次沒有動到模組職責或 `SERVER.refresh` 算法，`docs/工程架構手冊.md` 無需調整。
