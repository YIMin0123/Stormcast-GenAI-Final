# 圖鑑：點魚不再跳回最上面、滑鼠可以拖曳捲動清單

- 狀態：已提交
- 日期：2026-11-17
- 作者：Claude Opus 5.5
- 提交：本檔所在的那次提交（訊息開頭「圖鑑清單捲動」）
- 會動的檔案：src/tabletApps.js、docs/工程架構手冊.md

## 做了什麼
- 平板 HTML app 整頁重畫（`htmlApp.update` 換 innerHTML）時，標了 `data-keep` 的捲動區記住捲到哪、換完放回去。圖鑑左邊清單標 `data-keep="dex-<篩選>"`：點一條魚停在原位；換篩選（普通／少見…）因為名字不同，回到最上面。
- `dragScroll(el, sel)`：滑鼠左鍵按住清單上下拖就捲動（換算平板的 CSS 縮放），拖超過 5 像素才算拖曳，放開那一下點擊吞掉（不會順手選到魚）；一般點擊照常選魚。手指本來就能滑，只管滑鼠。目前只套在圖鑑清單。

## 為什麼
使用者：每次選魚清單都自動置頂；想用滑鼠像滾輪那樣直接拖。另外問圖鑑裡的魚是新版還是舊版——縮圖（`fishThumbs.js`）用的是遊戲裡同一個 `makeFishMesh` → `fishModel.js` 的新模型，沒有改。
