# 手機依瀏覽器更新頻率顯示幀率檔

- 狀態：已提交
- 日期：2026-11-16
- 作者：Codex
- 提交：同本次提交
- 會動的檔案：index.html、src/main.js、src/framePacer.js、tools/framePacer.test.js、docs/工程架構手冊.md

## 做了什麼
手機預設 30 FPS，取前景分頁的畫面回呼間隔，依穩定更新頻率開放 45、60、90 或 120 FPS。玩家的選擇有保存，實際可套用的上限取已觀測到的檔位。

## 為什麼
螢幕、瀏覽器與省電模式都可能影響網頁的更新頻率。以實測回呼頻率判定選項。

## 要知道的事
當頁確認過的選項會保留，避免短暫延遲時選項跳動。幀率上限仍受遊戲負載與瀏覽器限制。測試涵蓋 30、60、90、120、144 Hz 的判定，也在桌機 Chrome 觸控模式驗證切換所有選項。
