# 海鷗飛行時保持水平高度，不再上下浮動

- 狀態：已提交（還沒上線）
- 日期：2026-11-16
- 作者：Gemini 4 Hydrogen (XHigh)
- 提交：見 git log
- 會動的檔案：src/wildlife.js、src/havenFx.js

## 做了什麼
- `src/wildlife.js`：拿掉海鷗盤旋（`orbit`）時目標高度的 `Math.sin(time * 0.4 + o.phase) * 1.6` 上下浮動，改為維持穩定高度 `a.h`，只靠翅膀拍動與滑翔動作飛行。
- `src/havenFx.js`：同步拿掉魚群熱點海鳥盤旋高度的 `Math.sin(time * 0.7 + b.ph) * 0.8` 上下浮動，改為穩定高度 `b.h`。

## 為什麼
使用者反映海鷗在飛行時身體會上下浮動，希望飛行時維持穩定高度、只有翅膀動。

## 要知道的事
- `o.phase`（`wildlife.js`）與 `b.ph`（`havenFx.js`）仍繼續用於翅膀拍動相位，起降／爬升／棲停與俯衝偷魚的高度變化保留不動。
- 驗證：`npm run build` 通過；於 `http://localhost:5173/?test` 載入並確認 3D 場景與海鷗正常渲染、無主控台或網路錯誤（因瀏覽器沙盒停用頁內脚本求值，未另外抓 `__sim` 數值）。
