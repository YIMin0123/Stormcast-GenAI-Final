- 提交：見 git log（標題「更新資訊合併成一條」）

## 做了什麼
`UPDATES` 原本有 11 月 14 日到 17 日共十幾條，全部換成一條「近期更新總整理」（8 個重點，小細節不放）。

## 為什麼
使用者覺得更新資訊太長，要求合併成一個、只挑少數重點。

## 要知道的事
- 新條的 id 是 `2026-11-17-a`，不是 `-10`：id 是字串比大小，`-10` 會比 `-9` 小，舊玩家就不會亮小紅點。所以 announce.js 上方的說明改成「同一天多條用 -a、-b、-c……」，**別的 AI 之後在同一天再加更新資訊請接著用 -b**，並且加在這條上面。
- 舊的每條細節沒有保留（要看可以從 git 歷史翻 `src/announce.js`）。已經看過 `-9` 的玩家會再亮一次小紅點（因為內容整個換了）。
- 目前在做的「魚餌戰術與動態物價」那份日誌如果之後要加更新資訊，加在最上面、id 用 `-b`。
