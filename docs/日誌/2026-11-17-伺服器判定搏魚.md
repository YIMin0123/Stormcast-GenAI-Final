## 做了什麼

- 伺服器從第一則收線輸入開始，依自己收到輸入的時間算魚的拉力區間、張力、負荷和進度。只接受當前場次的布林按鍵狀態與下一個輸入序號。伺服器判定釣獲、跑魚或爆桿，原本只等最低秒數即可要求收魚的入口已移除。
- 頁面依本地按鍵預測力道並用伺服器快照校正，漁獲以伺服器結果為準。上鉤後四秒未收到初始按鍵即結束，搏魚最多兩分鐘，離開距離或換連線也會結束。舊版頁面拉竿會收到重新整理提示。工程手冊的搏魚說明已隨同一時間的 `70b60f3` 提交。

## 驗證

- 149 項回歸測試通過。以本機 8787 的實際 WebSocket 確認空等及偽造舊收魚訊息不發魚，按張力表收放可以釣獲。模擬 300 毫秒往返與抖動，透過新版客戶端判定畫面測得可釣獲並成交一次。`npm run build` 通過。
- 本機 Chrome `?test` 分頁驗證進房、咬鉤、第一次收線輸入與空等後跑魚。後續瀏覽器自動化遇到咬鉤逾時與頁面重載，真人收線手感仍待實機試玩。
