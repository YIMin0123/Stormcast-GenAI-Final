# 擴大人物站地範圍並對齊指棧／木棧板邊緣碰撞

- 狀態：已提交（還沒上線）
- 日期：2026-11-16
- 作者：Gemini 4 Hydrogen (XHigh)
- 提交：見 git log
- 會動的檔案：src/player.js、src/main.js、tools/collision.test.js

## 做了什麼
- `src/player.js`：把原本單點判定改為 `_pointSurface`，並在 `_surface(x, z, world)` 加入人物雙腳站地半徑 `FOOT = 0.18`（比身體撞牆半徑 `BODY = 0.32` 略小，符合鞋腳寬度），當中心點略探出木板邊或斜切轉角時只要腳底範圍內還有高度相近的地面就會穩穩撐住；已在水中游泳時不觸發腳邊拉回。另在 `_move` 中保留原本從板邊正對著船一步跨上去的行為（中心邁入水面時仍會檢查 `HOPS` 跨上船）。
- `src/main.js`：在 `walkGround`、`flyGround` 與木板腳步聲／陰影判斷為 `deckY` / `onDeck` 加上 `PIER_PLANK_PAD = 0.12`，對齊 `harbor3d.js` 實際畫出的木條外伸寬度（尤指 `0.8` 公尺寬的指棧兩側參差木條）。
- `tools/collision.test.js`：新增「人物站在棧板邊緣與指棧轉角時，站地半徑會撐住而不直接掉進海裡，游在旁邊也不會瞬移上岸」回歸測試。

## 為什麼
原本 `Player._surface` 只檢查中心一個零半徑點，加上 `walkGround` 的 `deckY` 未計入 `harbor3d.js` 木條凸出邊緣（`skirt + off` 約 `0.12` 公尺），在走上窄指棧轉角或貼著凸出木條走時，視覺上人還在木板上卻會直接掉進海裡。

## 要知道的事
- 驗證：`node --test tools/collision.test.js tools/gameplay.test.js tools/security.test.js`（38 項全數通過）、`npm run build` 通過，並於 `http://localhost:5173/?test` 實機確認角色穩站在指棧凸出板邊與轉角、無落水與主控台錯誤。
